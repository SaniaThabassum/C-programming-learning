# C-programming-learning
Learning C programming through Infosys Springboard, covering fundamentals, loops, arrays, strings, functions, recursion, and pointers while strengthening problem-solving and programming skills.

**C Programming Journey 🚀**

Welcome to my C Programming repository! 💻

This repository documents my journey of learning C programming through Infosys Springboard. As a second-year Artificial Intelligence and Machine Learning (AIML) student, I am building a strong foundation in programming, logical thinking, and problem-solving.

📚 Topics Covered

- C Programming Fundamentals – Introduction to C, program structure, syntax, and basic programming concepts.
- Variables and Data Types – Variable declaration, constants, and different data types.
- Input and Output – Using "printf()" and "scanf()" to interact with users.
- Operators – Arithmetic, relational, logical, assignment, and other operators.
- Conditional Statements – Decision-making using "if", "if-else", nested "if", and "switch" statements.
- Loops – Iteration using "for", "while", and "do-while" loops.
- Loop Control Statements – Using "break" and "continue" to control program execution.
- Arrays – Storing and processing collections of elements.
- Strings – Working with character arrays and string operations.
- Functions – Creating reusable functions, passing arguments, and returning values.
- Recursion – Understanding recursive functions and solving problems through recursion.
- Pointers – Learning memory addresses, pointer variables, and basic memory manipulation.
